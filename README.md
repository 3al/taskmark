# `[x]` Taskmark

Канбан-доска поверх Markdown-файлов в папке `tasks/` вашего проекта — **для вас и ваших
AI-агентов**. Задачи лежат рядом с кодом: ни базы, ни облака, ни регистрации. Вы правите
их мышью в браузере, агент — теми же файлами через свои скиллы.

Сделано функционально и просто: один сервер на несколько проектов, живая очередь,
drag-and-drop, развёртывание структуры задач и агентского окружения (скиллы, правила)
в пару кликов.

Стек: Python (FastAPI + uvicorn + watchdog) + React/Vite/Tailwind (собранный фронтенд в репозитории — Node.js не нужен).

## Требования

- Python 3.10+ (`py` на Windows, `python3` на macOS/Linux)
- Всё остальное ставится автоматически при первом запуске (fastapi, uvicorn, watchdog — в `taskboard/.venv`)

## Быстрый старт

1. Получить код: `git clone` или скачать ZIP (Code → Download ZIP) и распаковать.
2. Запустить из любого места:
   ```
   py taskboard.py          (Windows)
   python taskboard.py      (Windows без лаунчера py — например Python из Microsoft Store)
   python3 taskboard.py     (macOS/Linux)
   ```
   При первом запуске спросит подтверждение установки зависимостей (флаг `--yes` — не спрашивать).
   Откроется браузер на `http://127.0.0.1:8765`.
3. В шапке: **«+ проект»** → в окне указать путь к **корню** проекта (папка `tasks/` берётся внутри него) — строкой или выбрать папку в списке.
4. При первом открытии проекта спросит, **в каких средах** вы с ним работаете
   (Claude Code, opencode). Ответ запоминается в конфиге проекта и определяет
   состав поставки; изменить — **Настройки (⚙) → Среды агентов**.
5. Кнопка развёртывания создаст `board.md`, `create_task.py`, `set_status.py`,
   `epics.md`, `logs/` и окружение выбранных сред: скиллы, команды opencode,
   секцию правил TASK MANAGEMENT в `CLAUDE.md` / `AGENTS.md`.
6. Пользуйтесь: доска, очередь, создание задач, логи.

Запуск из папки конкретного проекта автоматически добавляет его в реестр
(если сервер уже работает — второй инстанс не стартует, а регистрирует проект).

## Возможности

- **Канбан** по статусам проекта — набор колонок настраивается
  (см. [«Жизненный цикл задач»](docs/help/04-lifecycle.md))
- **Требования этапа** — что должно быть выполнено, чтобы задача ушла с этапа:
  агент не уведёт её дальше молча, а вы переносите карточки как раньше
- **Исполнитель задачи** — кто занимается ею сейчас: отмеченные этапы спрашивают
  имя (агенту — отказ без него, вам — долг на карточке), список имён общий для
  всех проектов машины
- **Живая очередь** — приоритетные задачи сверху вниз
- **Поиск по доске** — живой фильтр по номеру, заголовку и содержанию задач,
  с подсветкой совпадений в открытой карточке
- **DnD**: карточки по всей доске (в настройках можно оставить только приём ↔ очередь), колонки (порядок per-project)
- **Что залежалось** — задача, простоявшая в статусе дольше порога и всё это
  время не правившаяся, показывает возраст нижней строкой превью
  (порог настраивается per-project)
- **Над чем работают сейчас** — карточка задачи, которую только что правили,
  светится кольцом; порог в минутах настраивается, ноль выключает подсветку
- **Блокировки и пауза** — видно, почему задача стоит: маркер на карточке, фильтр
  «⛔ стоят», простановка из открытой задачи; перенос стоящей задачи в работу
  переспрашивает, а агент такую задачу вовсе не берёт
  (см. [«Доска, очередь и задачи»](docs/help/02-board.md))
- **Создание задач** из UI: в подраздел бэклога или сразу в очередь (в начало/конец),
  с необязательным эпиком — известные ключи подсказываются, новый попадает в `tasks/epics.md`;
  ключ эпика виден на карточке доски, имя — в открытой задаче
- **Копия задачи** — форма создания, предзаполненная полями оригинала (название,
  описание, критерии, тип, эпик, блокировки и пауза); зовётся из меню карточки и
  из открытой задачи
- **Мультипроектность**: реестр проектов, переключение в шапке, путь проекта с копированием
- **Scaffold**: развёртывание структуры `tasks/` + агентское окружение выбранных сред
  (скиллы, команды `.opencode/commands/`, правила в CLAUDE/AGENTS) и — опционально —
  Knowledge Vault: `vault/SYS` с правилами и шаблонами заметок, скилл `write-vault`
- **Валидация** структуры: баннеры проблем, точечное восстановление кнопкой «Создать»,
  окно расхождений для скриптов, скиллов, команд и правил. Об отсутствии части
  окружения говорится так же, как об устаревании: молчаливых пробелов в поставке нет
- **Правленные скиллы не теряются**: инструмент помнит, что развернул, поэтому
  различает «отстал от шаблона» и «правили в проекте», а расхождение разрешается
  слиянием, шаблоном или «оставить свою версию»
- **Вьюер логов** `tasks/logs/`
- **Помощь** прямо в UI (кнопка «?»): та же документация, что в `docs/help/`,
  со ссылками из редактора пайплайна и баннеров
- **Обновления**: инструмент сообщает о новой версии и показывает, что в ней изменилось.
  Проверка включается только с вашего согласия — до него в сеть не выходит ничего
  (см. [«Обновления и версия»](docs/help/07-updates.md))
- **Настройки** из UI: порт, DnD, жизненный цикл задач, превью карточки,
  остановка/перезапуск сервера

## Управление сервером

- Запуск: `py taskboard.py` (флаг `--dev` — авто-перезагрузка при правках backend)
- Остановка/перезапуск: Настройки (⚙) → раздел «Сервер»
- Порт по умолчанию 8765 (меняется в настройках или `--port N`)

## Структура репозитория

```
taskboard.py            # bootstrap + запуск (единая команда)
docs/help/              # пользовательская документация (её же показывает кнопка «?»)
taskboard/
  backend/              # FastAPI: парсеры доски, DnD-операции, scaffold, watcher (SSE)
  frontend/             # исходники React (для разработки; нужен Node.js)
  frontend/dist/        # собранный фронтенд (закоммичен — Node не нужен)
  templates/            # шаблоны scaffold: tasks/ и агентское окружение
  requirements.txt
```

## Разработка

```
py taskboard.py --dev          # авто-перезагрузка backend при правках
cd taskboard/frontend
npm install && npm run build   # пересборка фронтенда (dist коммитится)

# тесты (stdlib unittest, из корня репозитория)
taskboard/.venv/Scripts/python.exe -m unittest discover -s taskboard/tests -t taskboard -v
```

## In English

**Taskmark** is a kanban board on top of plain Markdown files in your project's `tasks/`
folder — for you and your AI coding agents. No database, no cloud, no accounts: tasks live
next to your code, you edit them in the browser, the agent edits the same files through its
skills. One server serves several projects.

Requires Python 3.10+; everything else installs itself on first run. Start it with
`py taskboard.py` (Windows) or `python3 taskboard.py` (macOS/Linux), then open
`http://127.0.0.1:8765`.

**The interface and all documentation are in Russian**, and so are the agent instructions
it deploys into your project. There is no English localization yet — worth knowing before
you install.
