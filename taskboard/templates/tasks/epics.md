# Epics

_Реестр эпиков — единый источник имён. Задачи ссылаются на эпик только по ключу через frontmatter `epic: <ключ>`._

## Формат записи

```
## <Jira-ключ> — <Название эпика>
<краткое описание (опционально)>
```

## Как найти задачи эпика

Ищи `epic: <ключ>` в `tasks/TASK-*.md` (поле frontmatter).
