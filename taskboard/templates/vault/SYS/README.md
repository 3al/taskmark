# Knowledge Vault

Внешняя память проекта **{project}** — для разработчика и для агента.

## Зачем

При решении задачи агент тратит контекст на изучение кода. Волт позволяет
переиспользовать уже добытые знания вместо того, чтобы вычитывать их заново.

## Структура

- `SYS/` — системные заметки: правила ведения, шаблоны, таксономия тегов
- остальные папки — домены проекта, по одной папке на домен

## Типы заметок

- `business` — бизнес-концепция: что, зачем, правила
- `code` — реализация: файлы, поток данных, паттерны
- `system` — про сам волт

## Как пользоваться

1. Читай `SYS/structure.md` — правила ведения заметок
2. Ищи заметки по домену и тегам (`SYS/taxonomy.md`)
3. Пополняй волт при получении новых знаний — скилл `write-vault`

Папка `vault/` игнорируется git: это локальная память, а не часть репозитория.
Поиск по проекту (glob/grep) её обычно не видит — обращайся явными путями.
