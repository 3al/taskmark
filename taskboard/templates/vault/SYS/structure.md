# Структура заметок

## Фронтматтер

Каждая заметка ОБЯЗАТЕЛЬНО содержит YAML frontmatter:

```yaml
---
title:      # Человекочитаемый заголовок
created:    # YYYY-MM-DD
updated:    # YYYY-MM-DD
tags:       # Массив тегов из taxonomy.md
domain:     # Домен (system / домен проекта)
note-type:  # Тип: system / business / code
concept:    # (только для code) ссылка на business-заметку [[...]]
impl:       # (только для business) ссылка на code-заметку [[...]]
---
```

## Именование

- Файл: `kebab-case-latin-short.md`
- Папки: по доменам, одна папка на домен
- Запрещены: кириллица, пробелы, спецсимволы в именах файлов

## Содержание

### business-заметка

- **Что**: описание бизнес-концепции
- **Зачем**: мотивация, правила
- **impl**: ссылка на code-заметку

### code-заметка

- **Где**: файлы, классы, ключевые строки
- **Как**: поток данных, паттерн реализации
- **concept**: ссылка на business-заметку

## Обновление

- Не удаляй старые заметки — помечай `DEPRECATED` в начале
- Обновляй `updated` в frontmatter
- При изменении архитектуры — обновляй связанные code-заметки
