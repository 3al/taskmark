# С чего начать

Taskmark — канбан-доска поверх Markdown-файлов в папке `tasks/` вашего проекта.
Доска читает и правит `tasks/board.md` и `tasks/TASK-NNN-*.md`, поэтому с задачами
одинаково работаете вы в браузере и агент через файлы.

Один сервер обслуживает несколько проектов; переключение — в шапке.

> **Вы работаете кнопками на доске или просите агента.** Скрипты `tasks/*.py` и
> их команды — инструмент агента. В справке они приведены для полноты, вызывать
> их самому обычно не нужно.

## Добавить проект

**Из доски.** Кнопка **«+ проект»** в шапке:

- в поле — путь к **корню** проекта (`tasks/` создастся внутри);
- путь можно вставить или выбрать в списке папок: клик заходит внутрь,
  «↑ наверх» поднимается на уровень выше;
- на Windows над списком есть кнопки дисков (`C:\`, `D:\`) — клик открывает
  корень диска;
- папки с `tasks/` помечены словом «проект»;
- **«Открыть»** показывает в списке путь из поля, **«Добавить»** регистрирует
  проект.

**Из терминала.** Запуск лаунчера из папки проекта регистрирует её:

```
py C:\путь\к\taskboard.py      (Windows)
python C:\путь\к\taskboard.py  (Windows без лаунчера py)
python3 ~/путь/к/taskboard.py  (macOS/Linux)
```

- Если сервер уже работает, команда добавит проект в него и завершится.
- Регистрируется только папка, где `tasks/` содержит доску или конфиг. Иначе
  сервер откроет прежний проект и скажет об этом в консоли. Новую структуру
  разворачивайте кнопкой «+ проект» или флагом `--tasks-dir`.

**Убрать проект** — кнопка **✕** рядом с ним. Файлы на диске остаются.

## Выбрать среды агентов

При первом открытии проекта доска спросит, в каких средах вы работаете: Claude
Code, opencode, Codex. От ответа зависит, что разворачивается. Изменить —
**Настройки (⚙) → Агенты**, подробности — в
[«Агентское окружение и среды»](05-agentic.md).

## Развернуть структуру

Кнопка развёртывания создаёт недостающее:

- `tasks/board.md` — доска с разделами пайплайна;
- `tasks/_TEMPLATE.md` — шаблон новой задачи;
- `tasks/create_task.py`, `tasks/set_status.py` — скрипты создания задач и смены
  статуса;
- `tasks/notify.py` — уведомления на доску от агента;
- `tasks/epics.md` — реестр эпиков;
- `tasks/logs/` — папка логов;
- `tasks/.gitignore` — папка задач не попадает в репозиторий;
- окружение выбранных сред: скиллы, команды opencode, секция правил в
  `CLAUDE.md` / `AGENTS.md`, хуки и их подключение в настройках среды;
- по галочке — Knowledge Vault: `vault/SYS/` и скилл `write-vault`.

Существующие файлы развёртывание не перезаписывает (см.
[«Агентское окружение и среды»](05-agentic.md)).

## Сервер

**Настройки (⚙) → Общие:**

- **«Сервер»** — остановка и перезапуск. Порт по умолчанию 8765, меняется там же
  или флагом `--port N`.
- **«Запускать при входе в систему»** — на Windows галочка, на macOS и Linux
  показано, что прописать вручную. При таком запуске браузер не открывается —
  доска доступна по `http://127.0.0.1:8765`, а вывод пишется в
  `~/.taskboard/server_8765.log` (в имени — порт).

Проверка обновлений и задачи из чата работают, только пока Taskmark запущен.
