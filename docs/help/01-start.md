# С чего начать

taskboard — канбан-доска поверх Markdown-файлов в папке `tasks/` вашего проекта.
Источник правды — сами файлы: доска ничего не хранит внутри себя, а читает и правит
`tasks/board.md` и `tasks/TASK-NNN-*.md`. Поэтому с задачами одинаково работают
и вы через браузер, и агент через файлы.

Один сервер обслуживает несколько проектов сразу — переключение в шапке.

## Добавить проект

1. Кнопка **«+ проект»** в шапке → путь к **корню** проекта (папка `tasks/`
   берётся внутри него, создавать её заранее не нужно).
2. Проект можно добавить и из терминала — запуск лаунчера из папки проекта
   регистрирует её сам:
   ```
   py C:\путь\к\taskboard.py     (Windows)
   python3 ~/путь/к/taskboard.py (macOS/Linux)
   ```
   Если сервер уже работает, второй процесс не стартует — он просто добавит
   проект в реестр и выйдет.
3. Кнопка **✕** рядом с проектом убирает его из реестра. Файлы при этом не
   удаляются: доска забывает проект, а `tasks/` остаётся на диске.

## Выбрать среды агентов

При первом открытии проекта доска спросит, **в каких средах** вы с ним работаете
(Claude Code, opencode). Ответ определяет состав поставки: какие скиллы, команды
и файлы правил разворачиваются и проверяются на свежесть.

Спрашивается это один раз и запоминается в конфиге проекта; изменить —
**Настройки (⚙) → Среды агентов**. Подробности — раздел «Агентское окружение и среды».

## Развернуть структуру

Кнопка развёртывания создаёт всё, чего не хватает:

- `tasks/board.md` — доска со всеми разделами пайплайна;
- `tasks/create_task.py`, `tasks/set_status.py` — скрипты создания задач и смены статуса;
- `tasks/epics.md` — реестр эпиков;
- `tasks/logs/` — папка логов;
- окружение выбранных сред: скиллы, команды opencode, секция правил в `CLAUDE.md` / `AGENTS.md`.

**Развёртывание ничего не перезаписывает.** Файл, который разошёлся с шаблоном
(правленый скилл, свой `create_task.py`, дополненная секция правил), остаётся как
есть и попадает в список «Отличаются от шаблона» — привести его к шаблону можно
только точечно, кнопкой рядом с diff.
