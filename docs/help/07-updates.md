# Обновления и версия

## Окно «Обновление»

Кнопка **↑** в шапке открывает окно: установленная версия, доступная версия,
изменения и способ обновиться.

- Изменения показываются **за все пропущенные выпуски**: пять свежих, остальные —
  по кнопке.
- Точка на кнопке **↑** означает, что есть новая версия. Когда версия находится
  при открытой доске, приходит и уведомление.

## Проверка обновлений

Taskmark выходит в сеть только по вашему согласию: для проверки обновлений и,
если она включена, для [интеграции с Telegram](09-telegram.md). Режим проверки
выбирается в окне обновления:

- **Автоматически** — раз в сутки;
- **Вручную** — по кнопке «Проверить сейчас»;
- **Выключена** — без проверки; обновиться вручную по-прежнему можно.

Пока режим не выбран, запросов нет.

- Отправляется один GET-запрос за описанием выпуска; данные о вас и проектах не
  передаются.
- Адрес задаётся ключом `release_manifest_url` в `~/.taskboard/config.json`.
- Без сети доска работает как обычно; ошибка и адрес запроса видны в окне
  обновления. Ответ «404» обычно значит, что адрес недоступен.

## Как обновиться

**Копия из git** — кнопка **«Обновить и перезапустить»**. Сервер
останавливается, получает код релиза из вашего `origin`, доустанавливает
зависимости, проверяет результат и запускается заново; страница перезагрузится.
Это занимает до минуты.

При ошибке код возвращается к прежней версии, а окно покажет причину.
Установленные зависимости не откатываются.

После обновления окно показывает изменения между прежней и новой версией, пока
вы не нажмёте «Понятно». Кнопка **«Настроить требования этапов»** ведёт в
**Настройки (⚙) → Жизненный цикл**. Полная история — `CHANGELOG.md` в корне
Taskmark.

**Кнопки нет, если:**

- есть незакоммиченные правки;
- есть свои коммиты поверх релиза (их число будет названо);
- сервер запущен с `--dev`;
- git не найден или копия не из git.

Команды ручного обновления показываются всегда:

```
git fetch origin main --tags
git merge --ff-only v1.2.3
```

После ручного обновления перезапустите сервер: **Настройки (⚙) → Общие →
«Сервер» → «Перезапустить»**.

**Копия из архива** — скачайте новую версию и распакуйте поверх. Папку
`taskboard/.venv` переносить не нужно.

## Версия

Версия одна для сервера, интерфейса и шаблонов; хранится в `taskboard/VERSION`.

- Если сервер запущен со старой версией кода, повторный запуск лаунчера
  предупредит об этом в консоли. Помогает перезапуск сервера.
- Обновление может изменить шаблоны агентского окружения — тогда в проектах
  появится баннер (см. [«Агентское окружение и среды»](05-agentic.md)).
