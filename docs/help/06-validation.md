# Баннеры проблем

Доска сверяет проект с ожидаемой структурой и показывает расхождения над
колонками. Рядом с проблемой — кнопка, которая её исправляет, и **«?»**, который
открывает нужный раздел справки.

## Экраны вместо доски

- **Нет структуры или файла доски** — кнопка **«Развернуть структуру»**.
- **Папка задач недоступна по правам** — кнопка **«Убрать проект»** (файлы
  остаются на диске).

## Красный баннер — критично

Доска открыта только для чтения, пока проблема не исправлена:

- `board.md` не разбирается;
- в `board.md` нет раздела приёма задач — верните заголовок (`## Backlog`) или
  разверните структуру заново;
- в пайплайне нет ни одного статуса — настройте **Настройки (⚙) → Жизненный
  цикл**.

Отдельная красная строка под шапкой — ошибка последнего действия (например,
сервер не ответил). Кнопка **«скрыть»** убирает её.

## Жёлтый баннер — часть возможностей отключена

| Проблема | Кнопка | Что делает |
|---|---|---|
| Нет `create_task.py` | Создать | разворачивает скрипт и кнопку «+ Задача» |
| Нет `set_status.py` | Создать | разворачивает скрипт смены статуса |
| Нет `notify.py` | Создать | разворачивает скрипт уведомлений от агента |
| Нет `epics.md` | Создать | создаёт реестр эпиков |
| Нет `_TEMPLATE.md` | Создать | создаёт шаблон задачи |
| Нет папки логов | Создать | создаёт `tasks/logs/` и кнопку «Логи» |
| Нет разделов доски для статусов маршрута | Создать разделы | добавляет разделы по порядку маршрута |
| Скрипт или `_TEMPLATE.md` устарел | Подробности | окно расхождений |
| Скиллы, команды, правила или хуки не развёрнуты | Развернуть | разворачивает окружение выбранных сред |
| Хук не подключён в настройках среды | Подключить | добавляет запись в `.claude/settings.json` или `.codex/hooks.json` |
| Скиллы, команды, правила, хуки или файлы волта отличаются от шаблона | Подробности | окно расхождений |
| Не выбраны среды агентов | Настроить | спрашивает среды |
| Волт не развёрнут | Развернуть | создаёт `vault/SYS/` и скилл `write-vault` |
| Остались скиллы или команды выключенной возможности | Подробности | кнопка «Удалить» в окне расхождений |
| Рядом с правилами осталась старая секция Task Management | Подробности | кнопка «Удалить» в окне расхождений |
| `set_status.py` не знает о требованиях этапов | Обновить | обновляет скрипт |
| Рекомендованные требования не учитывают новый тип задачи | Дописать | добавляет тип в исключения |
| Ваши требования не настроены для нового типа задачи | Настроить | открывает настройки жизненного цикла |

Окно расхождений описано в [«Агентское окружение и среды»](05-agentic.md).

## Синий баннер — нет раздела очереди

В `board.md` нет раздела, из которого берут работу. **«Создать раздел»** добавит
его.

## Предупреждения

Расхождения в данных показываются в том же жёлтом баннере: первые пять и число
остальных. Работу они не отключают.

**Доска и файлы задач:**

- строка на доске есть, файла задачи нет;
- строка похожа на чужую: номер совпал, задача другая;
- ссылка в строке ведёт на старое имя файла;
- заголовок в строке не совпадает с файлом;
- файл задачи есть, строки на доске нет;
- раздел строки не совпадает со `status:` в файле;
- на доске есть разделы вне пайплайна.

**Блокировки:**

- `blocked_by` или `blocks` ссылается на несуществующую задачу;
- блокировка записана только с одной стороны;
- цикл: задачи ждут друг друга по кругу.

**Требования этапов:**

- требование объявлено с ошибкой (статус вне маршрута, повтор имени, нет
  идентификатора или параметра) — оно не сработает; исправляется в настройках,
  см. [«Жизненный цикл задач»](04-lifecycle.md);
- в задаче отмечено требование, которого нет в маршруте, — отметка ничего не
  закрывает; доска её не удаляет.

### Кнопка «Починить данные»

Появляется, если часть расхождений исправляется автоматически. Открывает список
правок: сначала предпросмотр, затем применение. **Правдой считаются файлы
задач**, доска подстраивается под них.

| Что нашли | Что сделает починка |
|---|---|
| Файл есть, строки нет | добавит строку в раздел по `status:` (незнакомый статус — в раздел приёма) |
| Строка не в том разделе | перенесёт её в раздел по `status:` |
| Ссылка на старое имя файла | исправит ссылку |
| Заголовок в строке не совпадает | возьмёт заголовок из файла |
| Строка без файла | перенесёт в раздел `## Потерянные` |
| Чужая строка с вашим номером | перенесёт в `## Потерянные`, вашему файлу добавит свою строку |
| Блокировка записана с одной стороны | допишет вторую сторону по `blocked_by` |
| `blocks` указывает на задачу, которая её не ждёт | уберёт ссылку |

- Ничего не удаляется. Если файл вернётся, следующая починка вернёт строку из
  `## Потерянные` на место.
- Строка считается своей, если ссылается на файл точным именем или совпадает с
  ним заголовком.
- Ссылки на несуществующие задачи, циклы и ошибки требований кнопка не трогает —
  их исправляют вручную или просят агента.
