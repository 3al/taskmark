# Доска, очередь и задачи

## Колонки

Колонки — статусы жизненного цикла проекта, слева направо по маршруту. Набор
настраивается в **Настройки (⚙) → Жизненный цикл** (см.
[«Жизненный цикл задач»](04-lifecycle.md)).

- **Порядок колонок** меняется перетаскиванием заголовка. Он хранится в браузере,
  свой для каждого проекта. Кнопка **«↺ колонки»** в шапке возвращает порядок
  пайплайна.
- **Свернуть колонку** — клик по её шапке; развернуть — клик по полосе. Свёрнутая
  колонка принимает перетаскиваемые задачи и хранится там же, в браузере.
- При поиске и фильтрах колонка с найденными задачами разворачивается сама.
- **Настройки (⚙) → Вид доски → «Сворачивать пустые колонки»** сворачивает колонки
  без задач и разворачивает, когда задача появится. Колонки, свёрнутые вручную,
  настройка не трогает; разворот пустой колонки вручную держится до перезагрузки
  страницы.

## Живая очередь

Очередь — колонка, из которой берут работу (действие «Брать работу из» в
настройках жизненного цикла). В шапке она подписана **живая очередь**.

Порядок в ней — приоритет: **первая сверху берётся следующей**, в том числе
агентом. Поднять задачу в очереди — значит поднять её приоритет.

## Поиск и фильтры

Поле **«Поиск по задачам»** в шапке фильтрует доску по мере ввода: по номеру,
заголовку и тексту файлов задач.

- Регистр не важен, спецсимволы ищутся как есть.
- В колонках остаются только совпавшие задачи; рядом с полем — сколько найдено.
- Совпадение в тексте показывается фрагментом на карточке и подсветкой в
  открытой задаче.
- Сбросить — крестик в поле или **Esc**.

**Отбор по эпику** — `epic:` с ключом в том же поле (`epic:E056-18500`, можно
`эпик:`):

- несколько эпиков — через запятую или повтором: `epic:E056-18500,E007-SPEC`;
- с текстом — через пробел: `epic:E056-18500 склад`;
- задачи без эпика не попадают; неизвестный ключ даёт пустую доску;
- кнопка **«На доске»** в окне эпика подставляет запрос сама.

**Отбор по размеру** — кнопки **S · M · L · XL** в шапке. Можно нажать несколько.
Задачи без размера не попадают.

**Фильтр «⛔ стоят»** показывает все заблокированные и поставленные на паузу
задачи.

Поиск и фильтры складываются. Пока фильтр включён, бросить задачу «в конец
подраздела» нельзя.

## Перетаскивание и меню карточки

- Карточку можно бросить на колонку (встанет в конец), на другую карточку
  (встанет перед ней) или в конец подраздела.
- Перемещение правит и строку в `board.md`, и `status:` в файле задачи. Дата в
  строке становится сегодняшней.
- **Настройки (⚙) → Жизненный цикл → «DnD по всей доске»**: сняв галку, вы
  оставляете мышью между колонками только «приём ↔ очередь». Сортировка внутри
  колонки разрешена всегда.
- Изменения, сделанные агентом, появляются на доске без перезагрузки.

**Правый клик по карточке** открывает меню:

- **Перенести в** — колонка из списка, задача встаёт в её начало. Вопросы те же,
  что при перетаскивании.
- **Копировать** — номер, содержимое задачи или **«Задачу целиком»** (см. «Копия
  задачи» ниже).

Меню закрывается по Esc, клику мимо или прокрутке.

## Почему задача стоит: блокировки и пауза

- **Блокировка** — задача ждёт другую: `⛔ TASK-013` на карточке.
- **Пауза** — задача ждёт внешнего обстоятельства: `⏸ пауза`, причина в
  подсказке и в открытой задаче. Статус пауза не меняет.

Стоящая карточка отмечена жёлтой полосой слева.

В открытой задаче:

- **«+ блокировка»** и **«+ пауза»** ставят простой, крестики снимают. Блокировка
  записывается сразу в обе задачи.
- В списке блокировки только задачи, которыми блокировать можно: без
  завершённых, отменённых и тех, кто сам ждёт эту задачу.
- Строка **«держит»** — задачи, которые ждут эту. Номера открываются кликом,
  **←** в шапке возвращает назад.

Правила:

- В последнем статусе маршрута и в отмене простоя нет: кнопок нет, а при переезде
  туда простой снимается сам.
- Блокер, дошедший до конца маршрута, приглушается с пометкой «можно снимать».
  Снимаете пометку вы.
- Перенос стоящей задачи **в работу** доска переспросит и предложит снять простой.
  В остальные статусы задача переезжает без вопросов.

## Долг этапа

Если у этапов есть требования (см. [«Жизненный цикл задач»](04-lifecycle.md)),
задача может уехать дальше, не выполнив их. Тогда на карточке `⚠` — в подсказке
список недостающего, в открытой задаче строка «⚠ долг».

- Требование проверяется **при выходе** с этапа.
- В последнем статусе маршрута и в отмене долга нет.
- Требование, исключённое для типа задачи, у задач этого типа не спрашивается.

Перетаскивание не запрещено: перед переносом с долгом доска спросит.

- **«Подтвердить и перенести»** — закрывает требования, которые подтверждаете вы
  (например, «проверку подтвердил человек»).
- Требования, которые закрываются работой (секция, поле), закрывает агент; до
  этого они висят долгом.
- **«Перенести без подтверждения»** — перенос, долг остаётся.
- При переносе в последний статус кнопка называется **«Закрыть без них»**:
  требования останутся невыполненными.

**Возврат назад снимает подтверждения** этапов, которые задача пройдёт заново.

## Отмена задачи

Перенос в отменённый статус требует причины — без неё доска перенос не выполнит.
Причина сохраняется в поле `cancel_reason` и видна в открытой задаче.

## Создание задачи

Кнопка **«+ Задача»**:

- **Куда** — в бэклог или в очередь (в начало или в конец). Подраздел бэклога
  выбирается по типу.
- **Описание** — редактор с панелью разметки и переключателем «Текст / Как
  выглядит». Абзацы разделяйте пустой строкой. **Ctrl+Enter** создаёт задачу.
- **Критерии приёмки** — предзаполнены первым пресетом. Можно выбрать другой
  пресет, сохранить свой текст кнопкой «Сохранить как пресет» или удалить свой
  пресет крестиком. Пресеты общие для всех проектов. Если описание уже содержит
  `### Критерии приёмки`, поле не нужно.
- **Тип** — новый функционал, баг, рефакторинг, уборка, обсуждение, дизайн или
  код-ревью.
- **Эпик** — ключ вроде `E056-18500`, известные подсказываются. Для нового ключа
  спросят имя.

Задачу создаёт скрипт `tasks/create_task.py` вашего проекта. Нет скрипта — нет
кнопки; разверните его кнопкой на баннере (см. [«Баннеры проблем»](06-validation.md)).

Размечать текст не обязательно: агент, взяв задачу в работу, оформит его, не
меняя формулировок.

### Копия задачи

**«Копировать → Задачу целиком»** в меню карточки или кнопка с плюсом у заголовка
открытой задачи открывают форму создания, заполненную полями оригинала: название,
описание, критерии, тип, эпик, блокировки и пауза. Унаследованный простой можно
снять крестиком. Копия создаётся в бэклоге.

## Открытая задача

Клик по карточке открывает файл задачи с разметкой.

- **Копирование** — кнопка у заголовка копирует содержимое задачи, кнопка у номера
  копирует номер.
- **Название, описание, критерии** — карандаш при наведении. Сохранить — галочка
  (для названия Enter, для многострочных полей Ctrl+Enter), отменить — Esc или
  крестик. Правится исходный markdown; панель разметки: жирный (Ctrl+B), курсив
  (Ctrl+I), код, блок кода, список, подзаголовок, ссылка.
- **Тип, размер, срок** — метки под заголовком, клик открывает выбор.
- **Эпик** — карандаш рядом с ключом или «+ эпик»; «снять эпик» убирает.
- **Исполнитель** — метка на этапах, которые его спрашивают (см.
  [«Жизненный цикл задач»](04-lifecycle.md)). Имена подсказываются, новое
  запоминается для всех проектов. Пока имени нет, на карточке `⚠`.
- **Клик по эпику, автору или исполнителю** открывает окно со всеми их задачами
  в порядке маршрута; клик по строке открывает задачу, **←** возвращает.
- **«+ комментарий»** внизу добавляет строку в конец «Комментариев» с подписью
  `доска`. Написанные комментарии не правятся.

## Карточка на доске

На превью карточки:

- **Метка типа** — кружок с буквой в правом верхнем углу.
- **Полоска плана** — доля закрытых пунктов чеклиста, зелёная, когда закрыты
  все. Нет, если плана нет, ни один пункт не закрыт или задача завершена.
- **Возраст** — «12 дней здесь», если задача лежит в статусе дольше порога и её
  файл давно не правили. Считается от даты перехода в `board.md`, без неё — от
  `created:`.
- **Срок** — словами («3 дня до срока», «проср. 2 дня»); вытесняет возраст.
- **Кольцо по контуру** — файл задачи правили только что.
- **Эпик, размер, `⚠`, `⛔`, `⏸`** — см. разделы выше.

В последнем статусе маршрута и в отмене нет возраста, кольца и предупреждений о
сроке.

**Настройки (⚙) → Вид доски:**

| Настройка | По умолчанию |
|---|---|
| Заголовок превью, px (12–18) | 14 |
| Строк заголовка (1–4) | 3 |
| Метаданные, px (10–14) | 12 |
| Метка типа задачи | вкл |
| Прогресс плана работы | вкл |
| Показывать возраст после стольки дней (0 — выкл) | 7 |
| Подсвечивать правленые за столько минут (0 — выкл) | 1 |

Размеры превью общие для всех проектов, пороги возраста и подсветки — свои у
каждого.

## Удаление задачи

**Настройки (⚙) → Жизненный цикл → «Удаление задач крестиком»** (по умолчанию
выключено) добавляет крестик на превью. После подтверждения задача удаляется
вместе с файлом **безвозвратно**; пометки блокировки у соседних задач
снимаются.

## Всплывающие уведомления

Уведомления появляются в правом верхнем углу: новая версия, задача из чата,
сообщение агента, ожидание ответа в среде агента.

- Тают через заданное время; отсчёт идёт, только пока вкладка видна.
- Наведение мыши останавливает отсчёт у всей стопки.
- Крестик закрывает одно, **«Закрыть все»** — всю стопку.
- Уведомление из другого проекта подписано его именем.
- Закрытая вкладка уведомлений не хранит.

Цвет — тон: голубой — сообщение или вопрос, зелёный — работа готова, жёлтый —
работа встала или ждёт разрешения, красный — поломка. Под сообщением агента —
имя его модели.

Когда агент зовёт и как работают хуки сред — в
[«Агентское окружение и среды»](05-agentic.md).

**Настройки (⚙) → Вид доски → «Всплывающие уведомления»** — для каждого
источника:

- **галочка источника** — показывать или нет;
- **«ждут закрытия»** — не таять по таймеру;
- **«звук»** — короткий сигнал.

Там же **«Показывать, сек»** (0 — висеть до закрытия) и общая громкость; при
отпускании ползунка звучит пробный сигнал. В новой вкладке звук начинает работать
после первого клика по странице.

**«Простой терминала, мин»** — через сколько минут ожидания ввода в Claude Code
приходит «Claude ждёт вашего ответа»: по умолчанию 3, 0 — звать сразу. Ответили
раньше — уведомление не приходит вовсе, а за одно ожидание оно приходит один раз.
Вопрос и запрос разрешения зовут сразу при любом значении.

## Клавиатура в списках

Во всех выпадающих списках:

| Клавиша | Действие |
|---|---|
| `↑` `↓` | двигают подсветку |
| `Enter` | выбирает |
| `Esc` | закрывает список |

## Логи

Кнопка **«Логи»** показывает файлы из `tasks/logs/`; без папки кнопки нет.

- Markdown отображается с оформлением, остальное — моноширинным текстом.
- Понимаются UTF-8 и UTF-16 с меткой, цветовые коды терминала убираются.
- Свежие файлы сверху; протоколы `-brainstorm-log.md` и
  `-brainstorm-team-log.md` отмечены подписью «брейншторм».
