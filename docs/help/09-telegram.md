# Задачи из чата Telegram

Сообщение в рабочем чате Telegram становится задачей у того, кого в нём
тегнули. Taskmark читает чат через вашего собственного бота.

```
#задача Обновить документацию по API @ivanov
```

Бот отвечает карточкой задачи: номер, заголовок, проект, статус.

## Как включить

**Настройки (⚙) → Telegram**, галочка включения. Пока она снята, Taskmark не
обращается к Telegram.

**1. Завести бота.** Напишите **@BotFather** команду `/newbot`, задайте название и
ник (оканчивается на `bot`). Вставьте полученный токен в поле и нажмите
**«Проверить»** — появится имя бота.

**2. Разрешить боту читать чат.** У @BotFather: `/mybots` → ваш бот → *Bot
Settings* → *Group Privacy* → **выключить**. Добавьте бота в рабочий чат.

**3. Привязать чат к проекту.** Напишите в чат любое сообщение — чат появится в
списке на вкладке. Выберите для него проект; дополнительные проекты отмечаются в
строке «и по суффиксу». Там же укажите **свой ник** в Telegram.

Токен можно сменить в любой момент. Сообщения, отправленные до смены токена,
новый бот не разбирает.

## Как писать сообщения

- **Хэштег** `#задача` — в любом месте сообщения.
- **Заголовок** — первое предложение или первая строка; остальное — описание.
- **Тег исполнителя** — ровно один. Если тегнуто несколько, задача не создаётся.
- **Картинка или файл** — текст пишется в подпись; сам файл в задачу не попадает.
  В альбоме подпись нужна у одного снимка.

```
#задача Обновить документацию по API. Начать с раздела про фильтры @ivanov
```

→ задача «Обновить документацию по API» с описанием «Начать с раздела про
фильтры».

Задачи из чата попадают в подраздел бэклога «Из Telegram», без типа и критериев.
Автор задачи — ник отправителя (если ника нет — отображаемое имя).

### Срок

```
#задача Обновить документацию @ivanov #срок 2026-09-12
#задача Обновить документацию @ivanov #срок 3 недели
```

- Дата `ГГГГ-ММ-ДД` (не в прошлом) или число с единицей: дни, недели, месяцы;
  `0 дней` — сегодня.
- Сокращения, часы, «завтра» и `12.09` не принимаются.
- `#срок` указывается один раз; при ошибке задача не создаётся, бот подскажет.
- Если бот просит обновить окружение — обновите скрипт создания задач кнопкой на
  баннере и повторите сообщение.

### Несколько проектов

Если чат привязан к нескольким проектам, имя проекта пишется через дефис:

```
#задача-Бэкенд Пересчитать индексы @ivanov
```

Доступны только проекты, привязанные к этому чату; на другое имя бот ответит
списком доступных.

## Список работы

```
#работа @ivanov
#работа @ivanov @petrov
#работа
```

- **С никами** — каждый тегнутый отвечает своим ботом списком своих незавершённых
  задач: заголовок, проект, статус, дата назначения, срок.
- **Без ников** — каждый бот присылает незавершённые задачи, которые в этом чате
  поставили вы.
- В список попадают задачи всех проектов, привязанных к этому чату.
- Если бот участника не запущен, ответа от него не будет.

`#работа` нельзя сочетать с `#задача` в одном сообщении — бот ничего не выполнит
и покажет, как разделить команды.

## Ответы бота

| Маркер | Значение |
|---|---|
| ✅ | задача создана |
| 📋 | список работы |
| 🔄 | статус задачи изменён |
| 🎉 | задача завершена |
| ⏰ | срок приближается |
| ⚠️ | сообщение нужно исправить |
| ❌ | внутренняя ошибка |

## Уведомления о движении задачи

Когда задача из чата переходит в отмеченный статус, бот пишет в тот же чат:
номер, заголовок, проект, «было → стало» и теги автора и ваш. Переход в
последний статус маршрута приходит карточкой 🎉 «Задача завершена», остальные —
🔄.

Статусы выбираются кнопкой **«в чат»** в **Настройки (⚙) → Жизненный цикл**. По
умолчанию отмечен последний статус маршрута. Кнопка видна, когда Telegram
включён.

Уведомления приходят только по задачам из чата, при любом способе смены статуса.

## Напоминания о сроке

**Настройки (⚙) → Telegram → «Напоминать о сроке за столько дней»** — три поля, по
умолчанию `7`, `3`, `1`. Очищенное поле отключает эту границу.

- Напоминание приходит, когда задача пересекает границу, — одно на границу.
- В день создания задачи напоминаний нет.
- Перенос срока запускает напоминания заново.

**Просрочка.** Со следующего дня после срока приходит карточка «Задача
просрочена». Частота — **Настройки (⚙) → Telegram → «Повторять напоминание о
просрочке»**:

- **раз в день** (по умолчанию);
- **раз в неделю**;
- **только один раз**.

Если срок перенесли и снова пропустили, начинается новая серия напоминаний.

Напоминания приходят только по задачам из чата и не приходят по завершённым и
отменённым.

## Если Telegram недоступен

Включите **«Свой путь до Telegram»** на вкладке Telegram и заполните одно из
полей. Снятая галочка — прямое соединение, адреса в полях сохраняются. Кнопка
«Проверить» проверяет текущий путь.

**Прокси:**

- `http://хост:порт`, `https://хост:порт` — HTTP-прокси;
- `socks5://хост:порт`, `socks5h://хост:порт` — SOCKS5-прокси;
- логин и пароль — в адресе: `socks5://имя:пароль@хост:15355`;
- без порта подставляется 1080 (SOCKS5), 80 (`http`), 443 (`https`);
- прокси MTProto (`tg://proxy?…`) не подходит.

Пароль в поле скрыт звёздочками; глазок справа показывает его, пока вы его
удерживаете.

**Свой адрес Bot API** — `https://ваш.домен`, если у вас есть свой прокси к
`api.telegram.org` или свой `telegram-bot-api`.

**Ошибка «Сертификат api.telegram.org не прошёл проверку»** — прокси
расшифровывает трафик и видит токен бота. Taskmark через такой прокси ничего не
отправляет; используйте другой.

Обрывы связи пишутся в консоль Taskmark или в `~/.taskboard/server_8765.log`.

## Что важно знать

- **У каждого свой бот.** Один токен нельзя использовать на нескольких машинах.
- **Доски локальные.** Если задачу поставили двоим, у каждого будет своя.
- **Бот видит чат только с момента добавления.**
- **Нет ответа — задача не создана.** Бот работает, только пока Taskmark
  запущен; Telegram хранит непрочитанные сообщения около суток. Включите
  **Настройки (⚙) → Общие → «Запускать при входе в систему»**.
- **Две машины** — заведите по боту на каждую и привяжите их к разным чатам.
