# Задачи из чата Telegram

Сообщение в чате Telegram становится задачей на доске. Таскборд читает чат через
бота, которого вы заводите сами, и заводит задачу у того, кого в сообщении
тегнули.

Сообщение выглядит так:

```
#задача Обновить документацию по API @ivanov
```

Бот отвечает реплаем: `TASK-042 · Обновить документацию по API → бэклог проекта «Мой проект»`.

## Как включить

Настройки → вкладка **Telegram**. Возможность выключена по умолчанию и включается
галочкой; пока она выключена, таскборд в сеть за сообщениями не ходит.

Дальше три шага.

**1. Завести бота.** Напишите в телеграме боту **@BotFather** команду `/newbot` и
ответьте на два вопроса — название и ник (ник должен кончаться на `bot`). В ответ
придёт токен: длинная строка вида `8123456789:AAH…`. Вставьте её в поле и нажмите
«Проверить» — таскборд покажет имя вашего бота.

**2. Разрешить боту видеть чат.** У @BotFather: `/mybots` → ваш бот → *Bot
Settings* → *Group Privacy* → **выключить**. Без этого бот видит только
сообщения, адресованные лично ему. Затем добавьте бота в рабочий чат как
обычного участника.

**3. Связать чат с проектом.** Бот узнаёт о чате, когда в нём пишут: отправьте в
нужный чат любое сообщение, и он появится в списке на вкладке сам. Рядом с именем
чата выберите проект, куда складывать задачи. Искать идентификатор чата не нужно.

Если из одного чата нужно писать в несколько проектов, отметьте остальные в
строке «и по суффиксу» под выбранным.

Там же укажите **свой ник** в телеграме: по нему бот отличает адресованное вам от
чужого.

## Что важно знать

- **Бот у каждого свой.** Один и тот же токен нельзя опрашивать с нескольких
  машин — участники будут перехватывать сообщения друг у друга. Каждый заводит
  своего бота и добавляет его в тот же чат.
- **Доски у всех локальные.** Если тегнули двоих, у каждого появится своя задача
  со своим номером — общей задачи на всех не существует.
- **Бот видит чат только с момента добавления.** Сообщения, написанные раньше, он
  не получит никогда.
- **Нет ответа — значит задача не доехала.** Бот живёт внутри запущенного
  таскборда: если его не запускали, отвечать некому. Повторите сообщение, когда
  таскборд будет запущен. Невыгребленные сообщения телеграм хранит около суток —
  дольше они не ждут, поэтому таскборд стоит держать запущенным.
- **Задачи из чата попадают в рубрику «Из Telegram»** в начале бэклога. У них нет
  ни типа, ни критериев приёмки: в сообщении их никто не называл, и проставляет
  их тот, кто берёт задачу в работу.

## Как разбирается сообщение

- **Хэштег** может стоять где угодно: `#задача сделать X` и `@ivanov глянь
  #задача сделать X` работают одинаково.
- **Заголовок** — первое предложение или первая строка, смотря что кончится
  раньше. Остальное уходит в описание задачи.
- **Тег исполнителя** — кому задача. Тегнули не вас — ваш таскборд промолчит.

```
#задача Обновить документацию по API. Начать с раздела про фильтры @ivanov
```

даёт задачу «Обновить документацию по API» с описанием «Начать с раздела про
фильтры».

## Если проектов несколько

Обычно чат привязан к одному проекту, и в сообщении ничего указывать не надо.
Когда из одного чата нужно писать в разные проекты, имя добавляется к хэштегу:

```
#задача-Бэкенд Пересчитать индексы @ivanov
```

Выбрать так можно **только среди проектов, привязанных к этому чату**: право
писать в проект даёт привязка в настройках, а не наличие проекта на вашей машине.
Имя вне списка бот не примет и ответит перечнем доступных. Основной проект
называть суффиксом можно — задача уйдёт туда же, куда и без него.
